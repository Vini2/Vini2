<p>The first automated tool to use assembly graphs to refine binning results from metagenomic contig-binning tools.</p>

<h3>GraphBin2</h3>
<p>A next-generation GraphBin approach that refines bins and assigns contigs to multiple bins when shared between species.</p>
<a href="https://github.com/metagentools/GraphBin2" target="_blank" rel="noreferrer">View project</a>
</article>

<p>An assembly graph-based metagenomic binning toolkit that combines GraphBin, GraphBin2, MetaCoAG, visualisation, and evaluation.</p>
<a href="https://github.com/metagentools/gbintk" target="_blank" rel="noreferrer">View project</a>
